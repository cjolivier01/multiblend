Multiblend can now be built with Bazel. Helper scripts are provided for
common workflows:

  ./bld              # Debug build (bazel build -c dbg //:multiblend)
  ./perf             # Optimised build (bazel build -c opt //:multiblend --copt=-Ofast)
  ./install.sh       # Run install tree staging (accepts optional --prefix)

The scripts accept additional flags which are forwarded to Bazel.

To stage an install tree manually (and optionally copy it to a prefix):

  # Display the staged tree path
  bazel run //:install_tree

  # Install into ~/.local
  bazel run //:install_tree -- --prefix="$HOME/.local"

Older manual build commands are kept below for reference.

The following command should work to build Multiblend on Linux:

  g++ -msse4.1 -pthread -ffast-math -Ofast -o multiblend multiblend.cpp -lm -lpng -ltiff -ljpeg

Harry van der Wolf suggests the following for Mac:

  [install home brew]
  brew install jpeg-turbo libjpeg libpng libtiff
  gcc -I/usr/local/opt/jpeg-turbo/include -L/usr/local/opt/jpeg-turbo/lib -std=c++14 -msse4.1 -pthread -ffast-math -Ofast -o multiblend multiblend.cpp -lm -lpng -ltiff -ljpeg -lstdc++
